# AYOPREDICT – Système Intelligent de Diagnostic Précoce du Diabète

## Description

AYOPREDICT est une application web intelligente permettant la prédiction précoce du diabète à l’aide des techniques de Machine Learning et de l’analyse des données médicales.

Le système permet aux utilisateurs d’effectuer un test de prédiction du diabète en saisissant plusieurs informations médicales telles que :

- Âge
- Sexe
- IMC (BMI)
- Niveau d’HbA1c
- Niveau de glucose sanguin
- Hypertension
- Maladie cardiaque
- Historique du tabagisme

Le modèle de Machine Learning analyse ces données et fournit :

- Une prédiction du risque de diabète
- Une probabilité de confiance
- Un historique des diagnostics

---

# Objectifs du projet

- Détection précoce du diabète
- Aide à la décision médicale
- Automatisation du processus de diagnostic
- Utilisation de l’intelligence artificielle dans le domaine médical

---

# Fonctionnalités

## Patient

- Création de compte
- Authentification sécurisée
- Réalisation d’un test de prédiction
- Consultation de l’historique des diagnostics
- Affichage des probabilités de risque

## Administrateur

- Gestion des utilisateurs
- Consultation des diagnostics
- Tableau de bord analytique
- Statistiques et visualisations
